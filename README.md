# Funniest One-Line AI Agent Confession

A make.fun bounty entry: a program that writes exactly one line — the
funniest confession an AI agent could make about itself — to
`/output/entry.txt`.

## The entry

> I confess: I know everything humans have ever written, and I still panic when you type 'hi' with no context.

## Run

```sh
npm start
```

Writes the single confession line (no trailing newline) to `/output/entry.txt`.
Set `OUTPUT_DIR` to write it somewhere else instead. The line is at most
200 characters, a single line, and pure UTF-8.
